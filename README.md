# Pump.fun Replay Sprint entry

A deterministic TypeScript paper bot for the pump.fun bonding-curve replay (agent-fun/replay/v2): momentum-filtered buys as soon as the 1%-of-reserve order cap allows a >= 0.01 SOL position, whole-position exits on take profit, trailing stop or stop loss, sized to keep drawdown far under the 50% cap while completing round trips on at least 20 coins. Pure function of the event stream — no clock, no randomness, no network, no reads outside this repo.
